## Overview

A Python program designed to calculate the perimeter and area of a triangle using three side lengths entered by the user. The program uses Heron's formula to calculate the area of a triangle when its three side lengths are known.

## Features

- Accepts three side lengths from the user.
- Calculates the perimeter of a triangle.
- Uses Heron's formula to calculate the area.
- Uses Python's built-in `math` module.
- Displays the calculated results with formatted decimal places.

## How to Run

1. Ensure Python 3 is installed.
2. Save the program as `main.py`.
3. Open a terminal in the project directory.
4. Run:

```bash
python main.py
```

Follow the prompts to enter the three side lengths.
